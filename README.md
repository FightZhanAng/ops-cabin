## 功能

| 页面 | 干什么 |
|------|--------|
| **总览** | 信号条（异常才亮灯）、磁盘分区读数、CPU / 内存 / 网络小数表、**长期趋势（CPU 与内存的 24 小时 / 7 天曲线）**、清理记录统计、**进程榜（按内存 / CPU 排）**、**联网体检**、**域名改写（hosts 体检）**、关注端口一览；每一格都是入口 |
| **磁盘** | 扫描「安全清理 / 开发缓存 / 大文件」→ 勾选 → 预览 → 清理；**大文件可整盘扫**（分区列表每颗盘一键）**或选目录**（可多选 ≤8 根，结果合并按大小排）；详情面板给路径与风险，可打开所在目录 |
| **端口** | **端口雷达**（关注端口亮灯，琥珀扫描线一圈 4.5s）+ **服务关注（该不该在跑）** + 全部监听端口表（搜索 / 协议筛选 / 排序）+ 变化记录；可看进程详情、结束进程 |
| **启动项** | 两个档：**开机自启**（五个来源：注册表三处 + 启动文件夹两处，标出路径已失效的残留与已被任务管理器禁用的项）与**计划任务**（任务计划程序里非微软自带的任务，标出上次运行失败的与已禁用的）；**行内开关可直接禁用/启用，路径失效的项可删除登记**（二次确认、只删登记不碰程序本体；需要管理员的项按次弹一次 UAC） |
| **体检** | 机器整体健康：**开机时长 / 待重启 / 报错设备 / 磁盘健康档 / 事件日志摘要（按来源聚合）/ 意外关机记录**；只读，不重启、不启用禁用、不清日志 |
| **设置** | 主题（浅色 / 跟随系统 / 深色）、**通知（四类信号各自开关 + 持续异常重复提醒 + 安静时段）**、白名单、清理计划、更新、危险区 |

侧栏常驻状态：导航项上直接挂读数（磁盘余量、服务异常数、自启残留数、窗口内的端口变化数、
有新版本），收起时退化成灯点并把读数折进 `aria-label` —— **不开页面也知道有没有事**。端口那部分走纯推送，
不为几个徽标新增任何轮询。（体检刻意不挂徽标：它的数据是全应用最贵的一份，而侧栏每分钟刷一次。）

**联网体检**是本机发布链路的体检入口：一次点按并行探测域名解析、GitHub 的 HTTPS(443) 与
SSH(22)、SSH-over-443 备用通道、GitHub API 可达性与系统代理，把「这次失败是网络还是代码」
在几秒内回答掉。域名叫到本机（hosts 改写 / 本地代理）会明确标出，不会假装解析正常；
证书不受信任时会**放宽校验再试一次**，通的话记为「读数」而不是「不通」——本地代理做 TLS 拦截
不等于通道不可用，一刀切成两条都会把人引到错误的方向去查。

**域名改写**（hosts 体检）是联网体检的另一半：体检说「`github.com` 解析到 `127.0.0.1`」，
它说**是谁改的**。只报三件确定的事 —— 指向本机 / 被 `0.0.0.0` 屏蔽 / 命中发布链路域名，
局域网映射一律不报（报得越宽，真正要看的那几条越容易被淹）；命中发布链路域名的排在最前，
否则会被成百条广告拦截埋掉。读文件按 BOM 判编码，三种写法（无 BOM `/` 带 BOM `/` UTF-16LE）都认。

**启动项**回答开机慢的真正原因：五个来源（注册表三处 + 启动文件夹两处）一次读全，并标出
**路径已失效的残留自启** —— 卸载软件时常常只删程序、忘了删自启项，于是每次开机白跑一次。
任务管理器禁用过的项单独一档（读 `StartupApproved` 的启用位），不会和「路径没了」混为一谈。
行内开关把「看到」接上「处理」，两条边界写死：**只会翻启用位或删登记，不碰程序本体**；
删除只对失效项开放（伪造的非失效删除请求会被主进程用自采集数据复核拒绝）。
需要管理员的动作走**按次提权**——注册表 HKLM / 公共启动文件夹每点一次弹一次 UAC
（弹窗身份是「运维舱」，不是 PowerShell），日常的 HKCU 项与用户启动文件夹全程无弹窗；
写完的每次动作都强制重读，界面永远对着真相。

**计划任务**是启动项的另一半：Run 键只覆盖开机那一瞬，真正在后台按时联网的大头（遥测上报、
自动更新、定时检查）全在任务计划程序里。它会跳过 `\Microsoft\*` 那一整片系统自带任务，
只列不是微软装的那些 —— 本机 180 个任务里正好有 17 个。判据上有两点是刻意的：
`LastTaskResult` 不按「非 0 即失败」判（调度器把自己的状态也记在这个字段上，
`0x41301`「正在运行」和 `0x41303`「尚未运行」都不是失败），以及**已禁用的任务单独一档** ——
它根本不会跑，报故障是让人去修一个没在跑的东西。行内开关与启动项同口径：用户自建的任务
通常免提权，任务 ACL 不放开的（多为系统托管）才弹一次 UAC；删除只有「路径失效」档开放 ——
一个还在按时跑的任务没有「删掉」的正当性，禁用就够了。

**体检**把散在四五个系统工具里的判断汇总到一处：开机时长、要不要重启、有没有故障盘、
有没有报错设备、事件日志里谁在反复报错、上次是不是没好好关机。两处口径值得说明：

- **「已禁用」的设备不算故障。** 你在设备管理器里关掉的东西不该亮红灯 —— 这一点连 Windows
  自己都同意（`pnputil /enum-devices /problem` 不把被禁用的设备列为问题设备）。
- **「有文件排队等下次开机处理」不是「要求重启」。** 注册表里那个
  `PendingFileRenameOperations` 常被当成重启标记，但它其实是应用自己排的延迟删除/替换队列：
  本机 24 条登记里实打实只有 8 个文件，同一个文件被登记了 3 次。按它报警等于劝你白重启一次。

四段采集并发跑（本机 3.8 秒），只读 —— 不重启、不启用禁用设备、不清日志。

**通知**只推四类事：关注端口有变化、关注服务挂起 / 恢复、计划扫描完成、发现新版本。
每一类在设置页有自己的开关，另有两条统一规则：

- **安静时段**（默认关闭）：区间内不推通知。它挡掉的只是「弹窗」这一层 —— 四类信号
  在界面里各有各的家（端口事件流水账 / 服务面板与侧栏徽标 / 磁盘页扫描记录 / 更新区块
  与侧栏徽标），被静音的消息仍然看得到。起止格式坏掉或起止相同时按「不静音」处理：
  宁可吵，不可哑 —— 一个静悄悄失效的通知开关比没有这个开关更糟。
- **异常持续时重复提醒**（默认开启）：服务挂着且没人管时每 30 分钟再提醒一次。
  关掉就只在刚挂时提醒一次 —— 那一次如果正好没看见，就再也不会知道。

服务盯梢跑在主进程（关着窗口也在盯），60 秒一拍；无关注项时完全不跑。「不在跑」的判据
与应用里的服务面板、侧栏徽标是**同一份代码** —— 禁用的服务停着不算异常。

## 下载与安装

到 [Releases](https://github.com/FightZhanAng/ops-cabin/releases/latest) 下载：

- `ops-cabin-x.y.z-setup.exe` —— 安装版（可改安装目录、建桌面快捷方式），**支持应用内自动更新**
- `ops-cabin-x.y.z-portable.exe` —— 免安装版（双击即用；更新请回下载页手动替换）

> 安装包未做代码签名，Windows SmartScreen 可能提示「未知发布者」：点「更多信息 → 仍要运行」。

## 磁盘清理安全吗

三道防线，任何一道拦下就不动：

1. **只删「本次扫描结果里、且被你勾选」的路径**（伪造路径会被清理器拒绝）；
2. **白名单**（设置页维护的保护目录）在扫描与清理时一律跳过；
3. **系统保护名单**（系统目录、程序目录等）同样跳过。

默认删除进**回收站**（可还原）；「永久删除」只在你明确选择时使用。

## 端口雷达怎么用

- 点监听表里的 ★ 或在关注区添加端口；被占用 / 被释放 / 换了占用者时，雷达亮灯并记入变化记录；
- 「端口变化通知」（设置页，默认开启）推 Windows 系统通知；「清理计划」按日 / 按周自动扫描
  （只扫不删），完成后发通知 —— 两条都可以单独关掉。

## 开发

```bash
pnpm install     # 依赖安装（国内网络可参考 .npmrc 里的 Electron 镜像设置）
pnpm dev         # 开发模式（Electron + Vite HMR）
pnpm typecheck   # 类型检查
pnpm build       # 构建主进程与渲染层产物
pnpm dist        # 出 Windows 安装包（release/ 目录）
```

技术栈：Electron 43 · electron-vite · React 19 · TypeScript · Tailwind CSS v4 · Radix UI。

**测试**：十一套端到端脚本在 `scripts/`（真实开窗口、驱动界面、断言 DOM 与 IPC），每套自带构建：

```bash
node scripts/e2e-check.mjs     # 主进程地基：窗口位置恢复 / 托盘 / 设置原子落盘
node scripts/e2e-scan.mjs      # 扫描引擎：大目录 / 取消 / 进度 / 白名单 / 多根合并与位置枚举
node scripts/e2e-disk.mjs      # 磁盘页闭环：扫描 → 勾选 → 清理 → 回收站 / 盘符快捷
node scripts/e2e-ports.mjs     # 端口采集：与外部 netstat 交叉比对
node scripts/e2e-ports-m5.mjs  # 端口页闭环：关注 / 变化检测 / 进程处置
node scripts/e2e-overview.mjs  # 总览页：指标推送与走势线
node scripts/e2e-settings.mjs  # 设置页：主题即时生效 / 白名单 / 计划 / 危险区
node scripts/e2e-update.mjs    # 更新流程（离线假版本驱动，不联网）
node scripts/e2e-smoke.mjs     # 冒烟：六页 × 深浅两轮，截图留档（164 项断言）
node scripts/e2e-autostart.mjs # 启动项/计划任务：开关 / 删除登记 / 受控助手直调
node scripts/e2e-portable.mjs  # 打包产物验证（需先 pnpm dist）
```

## 设计

界面是一台「仪表」，不是一块「仪表盘」：颜色是信号不是装饰（绿 / 黄 / 红只表状态，且必配文字）；
数据一律等宽字体右对齐成列——内嵌 [B612 Mono](https://github.com/polarsys/b612)（空客为驾驶舱显示屏
委托设计的字体，这也是「舱」的字面来源）；分区用 1px 发丝线拼合成整板而非漂浮卡片。
设计系统与逐页规范见 [`design-system/`](design-system/opscabin/MASTER.md)。

## 隐私

扫描结果、关注清单、设置全部存在本机。应用**除「检查更新」外不联网**。
