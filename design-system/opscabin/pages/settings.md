# Settings（设置）Page Overrides

> **PROJECT:** OpsCabin · **Page Type:** 桌面应用内页面（表单）
> 本文件规则**覆盖** MASTER.md；仅记录页面级增量与偏离。
>
> **校正说明：** 技能自动生成的通用表单建议大部分可用，已按本应用场景收敛重写。
> 条目依据本会话内技能检索：ux 域（可见 label、错误就近、渐进披露、危险确认、保存反馈）。

---

## 布局

- 单列分组表单（组间分隔线）：通用 / 通知 / 白名单（保护目录）/ 清理计划 / 更新 / 关于
- 危险区（清空白名单、清空历史）置底，与常规区视觉隔开

## 组件

- Switch 开关：放在行右侧，即改即存
- 白名单编辑器：列表 +「添加目录」（调系统目录选择器）+ 逐项删除
- 清理计划：周期（每日 / 每周 / 手动）+ 触发时间
- 关于：版本号与 Electron / Chrome / Node 版本（等宽小字）、检查更新入口

## 交互规则

- 每个字段有**可见 label**；说明文字放字段下方（Dim 色）
- 校验错误显示在字段旁，不集中堆在顶部（ux：error near field）
- 即改即存的设置给保存反馈（字段级"已保存"或轻量 toast）
- 危险区动作二次确认（ux：destructive confirm）

## 避免

- ❌ placeholder 当 label
- ❌ 一次性铺开所有高级选项（渐进披露）
